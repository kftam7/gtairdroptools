We are using truffle framework for smart contract development and deployment.

Files and usage
-----------

contracts/Airdrop.sol
This is our Main Contract file which you need to deploy. You can customize contract as per your requirement.

migrations/1_initial_migration.js
If you update Smart Contract to take constructor parameters, you need to specify in this file.

truffle-config.js
Update 'require(dotenv)' path to your directory

.env
File which contains 12 secret mnemonic phrases of your hd wallet in SEED_PHRASE variable.


Deploy smart contact
-----------

1. npm install

2. Copiling smart contract: 
truffle compile

3. Deploying smart contract (Choose network from truffle-config.js file)
truffle migrate --network=testnet

4. Verify smart contract on bscscan/etherscan (API Keys are needed)
truffle run verify Airdrop@{ContractAddress} --network testnet
e.g. truffle run verify Airdrop@0x510Aa9AF256CAa83d80873AE530d776383225817 --network=bsctestnet

5. Once smart contract is deployed and verified, you can interect it from bscscan/etherscan
